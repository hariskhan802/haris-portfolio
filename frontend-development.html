delivery_standard

What “done” means for frontend work.

A screen is not finished just because it matches a screenshot. The implementation should behave correctly, survive different states and remain understandable after handoff.

Responsive states

Desktop, tablet and mobile layouts designed deliberately rather than patched at the end.

Reusable UI

Shared components, patterns and visual rules so future screens stay consistent.

Real states

Loading, empty, error, disabled and success behavior included as part of the product experience.

Maintainable code

Clear structure and typed interfaces that another engineer can continue working with.
